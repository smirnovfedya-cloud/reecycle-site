# REE website agent instructions

This repository contains the production marketing website for REE — The Waste Reduction Company in the UAE.

## Production workflow

- `main` is the production branch.
- Every push to `main` runs `.github/workflows/deploy-pages.yml` and publishes to `https://reecycle.app/` through GitHub Pages.
- Before starting work, update from `origin/main` with a fast-forward-only pull. Never discard or overwrite existing uncommitted work.
- Do not change DNS, the custom domain, GitHub Pages settings, or deployment permissions unless the user explicitly asks.

## Where to edit

- React page and component source: `app/`
- Public images and other static assets: `public/assets/`
- SEO page definitions and reusable solution content: `content/`
- Static page shells and metadata: `static-site/`
- Production build output: `pages-dist/` — generated by the build; do not hand-edit or commit it.

## Required verification

For every public-site change:

1. Run `npm run build:pages`.
2. Run `npm test`.
3. Review the diff and confirm that only intended source files changed.
4. Commit with a clear message.
5. Push to `main` only when the user explicitly asks to publish.
6. Wait for the GitHub Pages workflow to succeed and verify the changed content on `https://reecycle.app/`.

## Content and design rules

- The public site is in English.
- Preserve the established dark-green, white and bright-orange visual system unless a redesign is explicitly requested.
- Prefer specific, plain commercial language over generic sustainability claims.
- Never invent client names, measurements, certifications, destinations, savings, diversion figures or case-study outcomes. Ask for confirmation when evidence is missing.
- Preserve existing accessibility labels, SEO metadata, responsive behaviour and reduced-motion behaviour.
- Keep WhatsApp and free site visit as the primary conversion actions unless instructed otherwise.
- Reuse real REE photography from `public/assets/real/` when available. Clearly identify any generated placeholder imagery that still needs replacement by real photography.

## Safe collaboration

- Multiple people or agents may work on this repository. Pull before editing and again before pushing.
- If `main` moved while work was in progress, reconcile the change without force-pushing.
- Never use destructive Git commands or force-push unless the repository owner explicitly requests it.
